# Orbit branding

The Orbit name, logos and app icons in this folder (and the copies derived from them in `web/frontend/brand/` and the
Android `res/` folders) are the Orbit project's own artwork. The Apache-2.0 license of the code does not grant use of
the Orbit name or logos (Apache-2.0 section 6, trademarks).

| File | Use |
|---|---|
| `orbit-banner.webp` | README / repository banner, static splash |
| `orbit-app-icon.webp` | App icon (legacy Android launcher icon) |
| `orbit-planet.webp` | Planet mark: Android adaptive icon foreground, favicon |
| `orbit-logo-stacked.webp` | Side menu logo (web, small) |
| `orbit-logo-stacked-tagline.webp` | Sign-in and setup screens |
| `orbit-logo-horizontal.webp` | Android TV home-screen banner (on a dark background) |

The files are trimmed to the artwork (no transparent margin). Sizes for each place are made from these masters.
